# Byterexの紹介

この記事は、ブログの表示を確認するためのサンプル記事です。

Byterexは、**AIとロボティクスで家事の自動化を目指すプロジェクト**です。最初の目標は、洗濯物を認識し、つかみ、分類するロボットを作ることです。

## 最初の目標

洗濯物を片付ける動作を、次の3つに分けて考えています。

1. カメラで洗濯物を認識する
2. ロボットアームでつかむ
3. 種類に応じて分類する

## システム構成

LeKiwi / LeRobotをベースに、ロボットアーム、カメラ、Raspberry Pi、AIアクセラレータなどを組み合わせていきます。

| 機材 | 役割 |
| --- | --- |
| ロボットアーム | 洗濯物をつかんで動かす |
| カメラ | 洗濯物や周囲の様子を捉える |
| Raspberry Pi・AIアクセラレータ | 認識や制御の処理を担う |
