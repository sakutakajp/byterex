# Byterex Project

Byterexは、AIとロボティクスを使って、これまで人間が行ってきた家事を自動化することを目指すプロジェクトです。

最初の目標は、**洗濯物を認識し、つかみ、分類するロボット**を作ること。

## 構成

LeKiwi / LeRobotをベースに、ロボットアーム、カメラ、Raspberry Pi、AIアクセラレータなどを組み合わせ、物体認識・操作・判断を一つのシステムとして統合していきます。

## 名前の由来

Byterexという名前は、コンピュータの **Byte** と恐竜の **T-Rex** を組み合わせたものです。  
ロボットアームを恐竜の頭のように見立て、「bite（噛む）」ように物をつかむ、小さな家事ロボットをイメージしています。
