# システム構成

Byterexは、LeKiwi / LeRobotをベースに、**洗濯物を認識し、つかみ、分類するロボット**の開発を目指しています。

## 基本構成

ロボットアーム、カメラ、Raspberry Pi、AIアクセラレータなどを組み合わせ、物体認識・操作・判断を一つのシステムとして統合していきます。

## 主な機材

- **移動ベース：LeKiwi** — ロボットの移動を担います。
- **ロボットアーム：SO-ARM101** — 洗濯物をつかみ、動かします。
- **カメラ** — 洗濯物や周囲の様子を捉えます。
- **Raspberry Pi・AIアクセラレータ** — 認識や制御の処理を担う構成を検討しています。

## 目指す動作

1. カメラで洗濯物を捉える
2. 洗濯物を認識し、つかむ対象を判断する
3. ロボットアームでつかみ、分類する
